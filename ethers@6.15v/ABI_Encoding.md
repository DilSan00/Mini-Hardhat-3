## 💻 Ethers.js: ABI Кодирование и Фрагменты

В то время как класс `Contract` используется для высокоуровневого взаимодействия, низкоуровневые классы `AbiCoder` и `Fragment` отвечают за точное бинарное кодирование и декодирование, требуемое стандартом **ABI (Application Binary Interface)**.

### 1. Класс `AbiCoder`

Это низкоуровневая утилита для кодирования и декодирования **сырых** данных ABI. Обычно разработчики предпочитают класс `Contract`, который использует `AbiCoder` внутри себя.

| Метод | Назначение | Примечание |
| :--- | :--- | :--- |
| `AbiCoder.defaultAbiCoder()` | Возвращает единичный (singleton) экземпляр `AbiCoder`. | Используется для доступа к утилите. |
| `abiCoder.encode(types, values)` | **Кодирует** массив значений JavaScript в бинарные данные ABI (строка hex). | Используется для кодирования аргументов. |
| `abiCoder.decode(types, data, loose?)`| **Декодирует** бинарные данные ABI в значения JavaScript. | Опция `loose` используется для совместимости со старыми, некорректно дополненными логами событий. |
| `abiCoder.getDefaultValue(types)`| Возвращает **значения по умолчанию** для заданных типов Solidity (напр., `0` для `uint`, `false` для `bool`). | |

### 2. Фрагменты (Fragments)

**Фрагмент** — это представление отдельного элемента из ABI контракта (функции, события, ошибки, конструктора и т. д.).

#### Абстрактный Класс `Fragment`

Это основа для всех конкретных фрагментов.

| Класс Фрагмента | Что представляет | Ключевые Свойства | Статический Метод |
| :--- | :--- | :--- | :--- |
| **`FunctionFragment`** | Функция/Метод | `selector` (хеш первых 4 байт), `stateMutability` (view, pure, payable). | `FunctionFragment.getSelector()` |
| **`EventFragment`** | Событие | `topicHash` (хеш для фильтрации), `anonymous`. | `EventFragment.getTopicHash()` |
| **`ErrorFragment`** | Custom Error (Solidity) | `selector`. | |
| **`ConstructorFragment`** | Конструктор | `payable`, `gas` (рекомендованный лимит). | |
| **`FallbackFragment`** | Fallback-функция | `payable`. | |
| **`StructFragment`** | Пользовательская структура | | |

* **Форматирование:** Метод `.format(format?)` позволяет получить строковое представление фрагмента в различных форматах (`"json"`, `"full"`, `"minimal"`, `"sighash"`).

***

### 3. Типы Параметров (`ParamType`)

Каждый аргумент функции или события внутри фрагмента представляется классом **`ParamType`**. Он подробно описывает тип Solidity.

| Свойство | Что описывает |
| :--- | :--- |
| `paramType.name` | Имя параметра (напр., `"amount"`). |
| `paramType.type` | Полное имя типа (напр., `"uint256[3][]"`). |
| `paramType.baseType` | Базовый тип (напр., `"address"`, `"array"`, `"tuple"`). |
| `paramType.indexed` | Является ли параметр **индексированным** (только для событий). |
| `paramType.components` | Компоненты (для типа **`tuple`**). |
| `paramType.arrayLength` | Длина массива (или `-1` для динамического). |

* **Обход (Walking):** Методы `paramType.walk(value, process)` и `paramType.walkAsync(value, process)` позволяют рекурсивно обойти значение, соответствующее этому типу, и применить к каждому его компоненту функцию `process`. Это используется, например, для асинхронного разрешения ENS-имен.
