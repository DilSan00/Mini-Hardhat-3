## 📝 Краткое и Понятное Изложение: Утилиты (Utilities)

Ethers.js включает множество простых функций для кодирования, работы с данными, математических операций, RLP и преобразования единиц.

### 1\. Преобразование Единиц (Unit Conversion)

Эти функции критически важны для работы с финансовыми величинами, такими как ETH, где необходимо переводить между человеко-читаемым десятичным представлением и целым числом в наименьшей единице (**wei**).

| Функция | Назначение |
| :--- | :--- |
| **`parseEther(ether)`** | Конвертирует **строку** (например, `"1.5"`) в **BigInt** (Wei), используя 18 десятичных знаков. |
| **`formatEther(wei)`** | Конвертирует **BigInt** (Wei) в **строку** (десятичное число), используя 18 знаков. |
| **`parseUnits(value, unit)`** | Конвертирует строку в BigInt, используя заданное количество десятичных знаков или имя единицы (например, `"gwei"`). |
| **`formatUnits(value, unit)`** | Обратная конвертация BigInt в строку, используя заданное количество знаков. |

### 2\. Помощники по Данным и Хешированию

Эти функции работают с бинарными данными (`BytesLike` — `0x`-строки или `Uint8Array`).

  * **`hexlify(data)`**: Возвращает `0x`-префиксное шестнадцатеричное строковое представление байтов.
  * **`concat(datas)`**: Объединяет несколько массивов байтов в один.
  * **`dataSlice(data, start, end)`**: Вырезает часть байтов.
  * **`zeroPadValue(data, length)`**: Дополняет байты **слева** нулями до заданной длины (для `uint` в Solidity).
  * **`zeroPadBytes(data, length)`**: Дополняет байты **справа** нулями (для `bytes` в Solidity).
  * **`isHexString(value, length?)`**: Проверяет, является ли значение корректной `0x`-строкой (опционально с проверкой длины).

### 3\. Кодирование Base58 и Base64

| Функция | Назначение |
| :--- | :--- |
| **`encodeBase64(data)`** / **`decodeBase64(value)`** | Кодирование и декодирование произвольных байтов в строку Base64. |
| **`encodeBase58(value)`** / **`decodeBase58(value)`** | Кодирование/декодирование **числовых** значений в строку Base58 (используется, например, в IPFS). |

### 4\. RLP (Recursive-Length Prefix)

RLP — это метод кодирования, используемый в Ethereum для сериализации вложенных структур данных (блоков, транзакций).

  * **`encodeRlp(object)`**: Кодирует структурированные данные в строку RLP.
  * **`decodeRlp(data)`**: Декодирует строку RLP обратно в структурированные данные.

### 5\. Строки и UTF-8

  * **`toUtf8Bytes(str, form?)`**: Конвертирует строку в массив байтов **UTF-8** (опционально с нормализацией).
  * **`toUtf8String(bytes, onError?)`**: Конвертирует байты UTF-8 обратно в строку.

````markdown
# 🔥 Ethers.js: Краткий Справочник

**Ethers.js** — это библиотека для взаимодействия с блокчейном Ethereum.

## 🛠️ 1. Установка и Подключение

### Установка
```bash
npm install ethers
````

### Основы Взаимодействия

| Объект | Роль | Основные операции |
| :--- | :--- | :--- |
| **Provider** | **Чтение** (Read-only) | `getBalance()`, `getBlockNumber()`, `call()` (симуляция). |
| **Signer** | **Запись** (Write/Подпись) | `sendTransaction()`, `signMessage()`, `getAddress()`. |

### Подключение

```javascript
import { ethers, BrowserProvider } from "ethers";

// 1. Подключение к MetaMask (в браузере)
const provider = new BrowserProvider(window.ethereum);
const signer = await provider.getSigner();
```

-----

## 📝 2. Транзакции и Контракты

### A. Отправка ETH / Общие Транзакции

```javascript
// Отправка 1 ETH
const tx = await signer.sendTransaction({
  to: "0xRecipientAddress",
  // Конвертация в Wei: 1.0 ETH = 10^18 Wei
  value: ethers.parseEther("1.0") 
});

const receipt = await tx.wait(); // Ожидание подтверждения
```

### B. Взаимодействие с Контрактами

Используйте класс `Contract` для вызова функций контракта.

```javascript
import { Contract } from "ethers";
const abi = ["function transfer(address to, uint amount)"];

const contract = new Contract("токен.eth", abi, signer); 

// Вызов функции контракта
const tx = await contract.transfer("получатель", amount);
```

| **`hexlify(data)`** | Конвертирует байты в `0x`-строку. |
| **`toUtf8Bytes(str)`** | Конвертирует строку в байты UTF-8. |
