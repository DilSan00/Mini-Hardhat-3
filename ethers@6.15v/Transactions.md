## 📝 Краткое Изложение: Транзакции

**Транзакция** — это основная единица, которая меняет состояние блокчейна Ethereum. В Ethers.js транзакция представлена объектом **`Transaction`**, который описывает операцию, подлежащую подписанию и отправке.

### 1\. Объект `Transaction`

Класс `Transaction` содержит все данные, необходимые для операции.

| Свойство | Назначение |
| :--- | :--- |
| **`to`** | Адрес получателя. `null` для развертывания контракта (`init` transaction). |
| **`data`** | Данные транзакции (например, вызов функции контракта или код для развертывания). |
| **`value`** | Количество ETH (в **wei**) для отправки. |
| **`nonce`** | Счетчик транзакций, отправленных с адреса отправителя. Используется для предотвращения повторного воспроизведения. |
| **`chainId`** | ID сети (для защиты от replay-атак). |
| **`gasLimit`** | Максимальное количество газа, которое транзакция может потратить. |
| **`gasPrice`** / **`maxFeePerGas`** / **`maxPriorityFeePerGas`** | Параметры оплаты комиссии (зависят от типа транзакции: Legacy, EIP-1559 и т.д.). |
| **`accessList`** | Опциональный список адресов/слотов (EIP-2930) для снижения стоимости газа. |
| **`blobs`** | Данные BLOB (EIP-4844) для транзакций типа Cancun. |
| **`.unsignedSerialized`** | Сериализованная версия транзакции **без подписи** (предобраз). Ее хеш является дайджестом, который нужно подписать. |
| **`.serialized`** | **Полностью подписанная** и сериализованная транзакция (готова к отправке). |

### 2\. Типы Транзакций (EIPs)

Объект `Transaction` поддерживает различные типы, соответствующие хардфоркам Ethereum:

| Метод | Соответствующий EIP | Назначение |
| :--- | :--- | :--- |
| **`.isLegacy()`** | Type 0 | Старая транзакция (до EIP-1559), использует только `gasPrice`. |
| **`.isBerlin()`** | EIP-2930 (Type 1) | Включает `accessList`. |
| **`.isLondon()`** | EIP-1559 (Type 2) | Включает `maxFeePerGas` и `maxPriorityFeePerGas`. |
| **`.isCancun()`** | EIP-4844 (Type 3) | Включает **BLOB-данные**. |

### 3\. Подпись и Верификация

Ethers.js предоставляет утилиты для работы с криптографией транзакций:

  * **`recoverAddress(digest, signature)`**: Восстанавливает **адрес** отправителя, который подписал заданный хеш (`digest`). Это основной способ верификации подписи транзакции.
  * **`computeAddress(key)`**: Вычисляет Ethereum-адрес по публичному или приватному ключу.

### 4\. Создание и Подписание

Транзакция обычно создается и подписывается с помощью объекта **`Signer`**:

1.  **Формирование запроса** (Transaction Request).
2.  **Заполнение недостающих полей** (`signer.populateTransaction(tx)` добавляет `nonce`, `gasLimit`, `chainId` и т.д.).
3.  **Подпись** (`signer.signTransaction(tx)`).
4.  **Отправка** (`signer.sendTransaction(tx)` — выполняет шаги 2 и 3, затем транслирует).

# 🔥 Ethers.js: Краткий Справочник

**Ethers.js** — это библиотека для взаимодействия с блокчейном Ethereum.

## 🛠️ 1. Установка и Подключение

### Установка
```bash
npm install ethers
````

### Основы Взаимодействия

| Объект | Роль | Основные операции |
| :--- | :--- | :--- |
| **Provider** | **Чтение** (Read-only) | `getBalance()`, `getBlockNumber()`, `getLogs()`, `call()` (симуляция). |
| **Signer** | **Запись** (Write/Подпись) | `sendTransaction()`, `signMessage()`, `getAddress()`. |

### Подключение

```javascript
import { ethers, BrowserProvider } from "ethers";

// 1. Подключение к MetaMask (в браузере)
const provider = new BrowserProvider(window.ethereum);
const signer = await provider.getSigner();
```

-----

## 📝 2. Транзакции и Контракты

### A. Отправка ETH / Общие Транзакции

Каждая **изменяющая состояние** операция — это транзакция, требующая **nonce** и оплаты газа.

```javascript
// Отправка 1 ETH
const tx = await signer.sendTransaction({
  to: "0xRecipientAddress",
  value: ethers.parseEther("1.0") // Конвертация в Wei
});

const receipt = await tx.wait(); // Ожидание подтверждения
```

### B. Взаимодействие с Контрактами

```javascript
import { Contract } from "ethers";
const abi = ["function transfer(address to, uint amount)"];

const contract = new Contract("токен.eth", abi, signer); 

// Вызов функции контракта (отправка транзакции)
const tx = await contract.transfer("получатель", amount);
```

### C. Криптография Транзакций

  * **Nonce**: Порядковый номер транзакции с адреса, предотвращает повторную отправку.
  * **`tx.unsignedHash`**: Хеш, который подписывается **приватным ключом** для авторизации транзакции.
  * **`recoverAddress(digest, signature)`**: Используется для проверки, **чей адрес** подписал транзакцию.

## 🔐 3. Утилиты

| Функция | Назначение |
| :--- | :--- |
| **`keccak256(data)`** | Основной хеш Ethereum. |
| **`id("string")`** | Хеширование **UTF-8 строки** (для идентификаторов). |
| **`verifyMessage(message, signature)`** | Восстанавливает **адрес** подписавшего сообщение (EIP-191). |
| **`solidityPackedKeccak256(...)`** | Хеширование данных в формате **Solidity packed**. |
