## 📍 Ethers.js: Адреса и Разрешение Имен (ENS)

**Адреса** — это фундаментальные идентификаторы в Ethereum. Ethers.js предоставляет утилиты для нормализации, валидации и работы с адресами, включая поддержку **ENS (Ethereum Naming Service)**.

### 1\. Форматирование и Валидация Адресов

| Функция | Назначение |
| :--- | :--- |
| `getAddress(address)` | **Нормализует** и **добавляет/проверяет контрольную сумму (checksum)** адреса. |
| | **Проверка Checksum:** Если адрес содержит смешанный регистр, проверяет его контрольную сумму (кодируется регистром букв). Если проверка не пройдена, выбрасывается ошибка. |
| `isAddress(value)` | Возвращает `true`, если значение является **валидным** адресом (включая проверку контрольной суммы). |
| `getIcapAddress(address)` | Конвертирует адрес в старый формат **ICAP** (больше не рекомендуется). |
| `isAddressable(value)` | Проверяет, реализует ли объект интерфейс **`Addressable`** (`Signer`, `Contract`). |

### 2\. Адреса Развертывания Контрактов

Ethers.js может предсказать адрес контракта до его развертывания, используя стандарты `CREATE` и `CREATE2`.

| Функция | Назначение |
| :--- | :--- |
| `getCreateAddress(tx)` | Вычисляет адрес, который получится в результате обычной операции **`CREATE`** (использует адрес отправителя `from` и его `nonce`). |
| `getCreate2Address(from, salt, initCodeHash)` | Вычисляет адрес, который получится в результате операции **`CREATE2`** (детерминированный адрес, зависящий от адреса отправителя, **salt** и хеша кода инициализации). |

### 3\. Разрешение Имен (ENS Resolution)

**ENS-имена** (`name.eth`) должны быть асинхронно разрешены в адрес.

| Функция/Интерфейс | Назначение |
| :--- | :--- |
| **`resolveAddress(target, resolver?)`** | **Главная функция** для получения адреса из любого поддерживаемого формата: обычный адрес, Promise\<Address\> или **ENS-имя**. |
| | **Асинхронно:** Разрешает ENS-имена (требует `resolver`, обычно `Provider`). |
| **`AddressLike`** | Тип данных: любая строка (адрес, ENS), Promise\<string\> или `Addressable`. |
| **`Addressable`** | Интерфейс: объекты, которые могут асинхронно предоставлять свой адрес (напр., `Signer`, `Contract`). |
| **`NameResolver`** | Интерфейс: объекты, способные разрешать ENS-имена (напр., `Provider`). |

**Важно:** Для разрешения ENS-имени (`"ricmoo.eth"`) необходимо передать объект-резолвер (обычно `Provider`), иначе будет выброшена ошибка.
