## 📝 Краткое и Понятное Изложение: Объект Contract

Объект **`Contract`** в Ethers.js — это основной инструмент для взаимодействия с развернутыми смарт-контрактами. Это "мета-класс", который динамически адаптируется под **ABI** контракта, предоставляя вам удобный JavaScript-интерфейс для вызова его методов, отправки транзакций, а также прослушивания и запроса событий.

### 1\. Создание и Подключение

Основной класс для работы с контрактами — **`BaseContract`** (или его нетипизированный вариант **`Contract`**).

#### Конструктор

Создание нового экземпляра контракта:

```typescript
new BaseContract(target: string | Addressable, abi: Interface | InterfaceAbi, runner?: null | ContractRunner)
```

  * **`target`**: Адрес контракта (или ENS-имя).
  * **`abi`**: Интерфейс контракта (JSON или Human-Readable ABI).
  * **`runner`**: Объект, который определяет возможности:
      * **`Provider`** (только чтение)
      * **`Signer`** (чтение и запись)

#### Свойства

| Свойство | Назначение |
| :--- | :--- |
| **`.interface`** | Объект, представляющий ABI контракта. |
| **`.runner`** | Текущий подключенный **`Provider`** или **`Signer`**. Определяет, можно ли отправлять транзакции. |
| **`.target`** | Адрес (или ENS) контракта, к которому подключен объект. |
| **`.filters`** | Объект, содержащий все доступные **события** контракта для создания фильтров. |
| **`.fallback`** | Доступ к функциям `fallback` или `receive` контракта (если они есть). |

#### Методы подключения

Эти методы создают новый экземпляр контракта с измененным подключением:

  * **`.connect(runner)`**: Возвращает новый контракт, привязанный к другому **`Provider`** или **`Signer`** (например, переход от чтения к записи).
  * **`.attach(target)`**: Возвращает новый контракт с тем же ABI и `runner`, но с другим адресом **`target`**.

### 2\. Взаимодействие с Методами Контракта

Методы контракта доступны как функции-члены объекта `Contract` (например, `contract.transfer(...)`). У каждого метода есть дополнительные служебные функции.

| Метод | Назначение |
| :--- | :--- |
| **`method(...)`** | **Вызов метода**. Если подключен к **`Signer`** — отправляет транзакцию. Если к **`Provider`** и метод `view`/`pure` — выполняет `staticCall`. |
| **`.staticCall(...)`** | **Симуляция/Вызов для чтения** (`eth_call`). Выполняет метод как операцию только для чтения, не отправляя транзакцию. Используется для методов `view`/`pure` или для предварительной проверки транзакций. |
| **`.send(...)`** | **Отправка транзакции**. Отправляет транзакцию для метода (только если подключен к **`Signer`**). |
| **`.estimateGas(...)`** | **Оценка газа**. Вычисляет необходимое количество газа для выполнения транзакции. |
| **`.populateTransaction(...)`** | Создает **объект транзакции** для данного вызова метода, который можно подписать вручную. |

### 3\. Работа с Событиями (Events)

События используются для прослушивания и запроса исторической информации.

#### Типы EventName

События можно указывать несколькими способами:

1.  **`string`**: Имя события (например, `"Transfer"`).
2.  **`contract.filters.EventName`**: Функция-фильтр без параметров.
3.  **`contract.filters.EventName(...)`**: Функция-фильтр, вызванная с параметрами (например, адрес `from` или `to`) для создания более точного фильтра.

#### Прослушивание

  * **`.on(event, listener)`** / **`.addListener(event, listener)`**: Добавить слушателя для события.
  * **`.once(event, listener)`**: Добавить слушателя, который будет удален после первого срабатывания.
  * **`.off(event, listener)`** / **`.removeListener(event, listener)`**: Удалить слушателя.
  * **`.removeAllListeners(event?)`**: Удалить всех слушателей для указанного события или для всех событий.

#### Запрос истории

  * **`.queryFilter(event, fromBlock?, toBlock?)`**: Запрашивает исторические данные о событиях в указанном диапазоне блоков. Возвращает массив **`EventLog`**.

### 4\. Транзакции и Квитанции (Receipts)

  * **`ContractTransactionResponse`**: Возвращается после отправки транзакции. Содержит метод **`.wait(confirms?, timeout?)`**.
  * **`ContractTransactionReceipt`**: Возвращается после успешного майнинга транзакции. Содержит **`.logs`**, где все логи, соответствующие ABI контракта, уже разобраны (спарсены) в объекты **`EventLog`**.

## 📝 Взаимодействие с Контрактами

Объект `Contract` — это основной интерфейс для работы с развернутым смарт-контрактом. Он создается на основе **адреса**, **ABI** (Application Binary Interface) и **runner** (`Provider` или `Signer`).

### 1. Создание и Подключение

Контракт должен быть подключен к `Provider` для чтения или к `Signer` для отправки транзакций.

```javascript
import { Contract, Provider, Signer } from "ethers";

const abi = ["function getValue() view returns (uint)", "function setValue(uint)"];
const contractAddress = "0x...";

// Только чтение:
const readContract = new Contract(contractAddress, abi, provider); 

// Чтение и Запись:
const writeContract = readContract.connect(signer); // Используем Signer для записи
````

### 2\. Вызов Методов

Вы можете напрямую вызывать методы контракта. Их поведение зависит от подключенного `runner`:

| Тип метода | Подключение к `Provider` | Подключение к `Signer` |
| :--- | :--- | :--- |
| **`view`** / **`pure`** | Выполняется **локальный вызов** (`staticCall`). | Выполняется **локальный вызов** (`staticCall`). |
| **Изменяющий состояние** | **Ошибка**. Невозможно отправить транзакцию. | Отправляется **транзакция** (`send`). |

#### Дополнительные опции вызова

Каждый метод контракта имеет специальные функции:

```javascript
// Вызов view-функции
const value = await writeContract.getValue(); 

// Симуляция отправки транзакции (проверка без майнинга)
const simResult = await writeContract.setValue.staticCall(123);

// Оценка газа
const gasLimit = await writeContract.setValue.estimateGas(123);

// Отправка транзакции
const tx = await writeContract.setValue.send(123);
const receipt = await tx.wait(); // Ожидание подтверждения
```

### 3\. События (Events)

Ethers позволяет прослушивать события в реальном времени (`on`) или запрашивать исторические данные (`queryFilter`).

```javascript
// 1. Прослушивание всех событий "Transfer"
writeContract.on("Transfer", (from, to, amount, event) => {
    console.log(`Transfer: ${from} -> ${to}, Amount: ${amount}`);
    event.removeListener(); // Удалить слушателя после первого срабатывания
});

// 2. Использование фильтра для конкретного адреса
const filterTo = writeContract.filters.Transfer(null, "0xReceiverAddress");
writeContract.on(filterTo, (from, to, amount) => {
    // ...
});

// 3. Запрос исторических событий (последние 100 блоков)
const events = await writeContract.queryFilter("Transfer", -100, "latest");
console.log(`Найдено ${events.length} исторических событий.`);
```
