## 📝 Краткое и Понятное Изложение: Криптографические Функции

Криптографические примитивы — это фундаментальные строительные блоки, обеспечивающие безопасность и функциональность Ethereum. Ethers.js предоставляет к ним прямой доступ.

### 1\. Хеш-Функции (Hash Functions)

Хеш-функции преобразуют входные данные любого размера в фиксированный набор байтов (хеш). Они используются для создания уникальных идентификаторов. **Важно:** все эти функции ожидают входные данные в виде байтов (`BytesLike`).

| Функция | Алгоритм | Назначение | Примечание |
| :--- | :--- | :--- | :--- |
| **`keccak256(data)`** | **KECCAK256** | **Основной хеш-алгоритм Ethereum.** Используется для адресов, хешей транзакций и блоков. | Для хеширования **UTF-8 строк** используйте функцию `id()`. |
| **`sha256(data)`** | SHA2-256 | Стандартный криптографический хеш. | |
| **`sha512(data)`** | SHA2-512 | Более длинный криптографический хеш. | |
| **`ripemd160(data)`** | RIPEMD-160 | Криптографический хеш. | |

```javascript
// Вычисление хеша KECCAK256 (ожидает байты: "0x...")
const hash = keccak256("0x1337"); 
// '0x2636a8beb2c41b8ccafa9a55a5a5e333892a83b491df3a67d2768946a9f9c6dc'
```

### 2\. HMAC (Hash-based Message Authentication Code)

HMAC используется для подтверждения того, что сообщение было аутентифицировано с помощью определенного ключа.

  * **`computeHmac(algorithm, key, data)`**: Вычисляет HMAC для `data`, используя секретный `key` и указанный `algorithm` (`"sha256"` или `"sha512"`).

### 3\. Функции Вывода Ключа на Основе Пароля (PBKDF)

Эти функции создают криптографический ключ из удобного для человека пароля, делая подбор пароля более трудоемким.

| Функция | Алгоритм | Назначение | Примечание |
| :--- | :--- | :--- | :--- |
| **`pbkdf2(...)`** | PBKDF2 | Используется для расшифровки **старых** файлов кошельков. | **Устаревший.** Не рекомендуется для новых проектов. |
| **`scrypt(...)`** | **scrypt** | **Рекомендуется.** Использует много памяти и CPU, что замедляет brute-force атаки. | Асинхронная версия (`scrypt`) предпочтительнее синхронной (`scryptSync`) для предотвращения зависания UI. |

### 4\. Генерация Случайных Значений

  * **`randomBytes(length)`**: Генерирует криптографически безопасные случайные байты указанной `length`.

### 5\. Подписание (Signing)

Процесс подписи основан на алгоритме **ECDSA** (Elliptic Curve Digital Signature Algorithm) и используется для создания электронных подписей для транзакций и сообщений.

#### Класс `SigningKey`

Управляет операциями с закрытым и открытым ключом.

  * **`new SigningKey(privateKey)`**: Создает объект `SigningKey` из приватного ключа.
  * **`.privateKey`** / **`.publicKey`** / **`.compressedPublicKey`**: Доступ к ключам в разных форматах.
  * **`.sign(digest)`**: Создает **`Signature`** для заданного хеша (дайджеста).
  * **`.computeSharedSecret(other)`**: Вычисляет общий секрет по алгоритму **ECDH** (Elliptic Curve Diffie-Hellman).

#### Класс `Signature`

Объект, представляющий цифровую подпись. Подпись состоит из:

  * **`r`** и **`s`**: Основные компоненты подписи.
  * **`v`** (или **`yParity`**): Используется для восстановления открытого ключа (чей ключ подписал сообщение) и для **EIP-155** (включает ID сети).

#### Восстановление Ключа

  * **`SigningKey.recoverPublicKey(digest, signature)`**: Восстанавливает открытый ключ (адрес) того, кто создал подпись для данного дайджеста. Это ключевая функция для проверки подписи.

## 🔐 Криптографические Функции

Ethers.js предоставляет доступ к криптографическим примитивам, необходимым для безопасности Ethereum, включая хеширование, HMAC и управление ключами.

### 1. Хеш-Функции

| Функция | Алгоритм | Назначение |
| :--- | :--- | :--- |
| **`keccak256(data)`** | KECCAK256 | **Основной хеш Ethereum.** Используется для идентификации транзакций, блоков и адресов. |
| **`sha256(data)`** | SHA2-256 | Стандартный криптографический хеш. |

```javascript
import { keccak256, toUtf8Bytes } from "ethers";

// KECCAK256 ожидает байты (DataHexString или Uint8Array)
const emptyHash = keccak256("0x"); 

// Чтобы хешировать UTF-8 строку, сначала преобразуйте ее в байты
const dataBytes = toUtf8Bytes("hello world");
const dataHash = keccak256(dataBytes); 
````

### 2\. Подписание и Ключи

Класс `SigningKey` используется для управления ключами, а его статический метод `recoverPublicKey` — для проверки подписи.

```javascript
import { SigningKey, id, computeAddress } from "ethers";

// 1. Создание ключа для подписи
const privateKey = id("my-secret-key-phrase"); 
const signingKey = new SigningKey(privateKey);

// 2. Подписание дайджеста (хеша сообщения)
const digest = id("message to sign"); 
const signature = signingKey.sign(digest);

// 3. Восстановление открытого ключа из подписи (для проверки)
const recoveredPubKey = SigningKey.recoverPublicKey(digest, signature);

// 4. Вычисление адреса Ethereum из открытого ключа
const walletAddress = computeAddress(recoveredPubKey);
```

### 3\. Функции Вывода Ключа (PBKDF)

Используются для создания криптографических ключей из паролей. **`scrypt`** является предпочтительным, так как он устойчив к атакам перебором.

```javascript
import { scrypt } from "ethers";

// Асинхронное выполнение scrypt (рекомендуется)
const key = await scrypt(passwordBytes, saltBytes, 1024, 8, 1, 32); 
```
