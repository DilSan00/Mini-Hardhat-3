# 🛠️ Hardhat 3: Полный Набор для Разработчика Ethereum

**Hardhat 3** — это гибкая и расширяемая среда разработки, которая делает написание, тестирование и деплой смарт-контрактов простым и эффективным.

## 🚀 Начало Работы (Getting Started)

### 1\. Установка

Вам нужен **Node.js v22+**.

1.  Создайте папку проекта и перейдите в неё:
    ```bash
    mkdir hardhat-example && cd hardhat-example
    ```
2.  Инициализируйте проект (используйте настройки по умолчанию для быстрого старта):
    ```bash
    npx hardhat --init
    ```
    Это автоматически установит все зависимости и настроит проект с использованием **Node.js test runner** и библиотеки **Viem**.

### 2\. Структура Проекта (По умолчанию)

| Папка/Файл | Назначение |
| :--- | :--- |
| `hardhat.config.ts` | **Главный конфиг** (Solidity, сети, плагины). |
| `contracts/` | Ваши **Solidity-контракты** (`.sol`) и **Solidity-тесты** (`.t.sol`). |
| `test/` | **TypeScript/JavaScript тесты** (интеграционные, E2E). |
| `ignition/modules/` | **Модули деплоя Hardhat Ignition** (декларативное описание, как развернуть контракты). |
| `scripts/` | Пользовательские **скрипты** для автоматизации задач (`npx hardhat run ...`). |

## 💻 Разработка и Тестирование Контрактов

### Контракты

  * Пишите `.sol` файлы в папке `contracts/`.
  * **Компиляция:**
    ```bash
    npx hardhat build
    ```

### Тестирование: Solidity vs. TypeScript

Hardhat 3 поддерживает тесты на Solidity и TypeScript, которые запускаются на **локальном, быстром блокчейне**.

| Тип Теста | Solidity (`.t.sol`) | TypeScript (`.ts`) |
| :--- | :--- | :--- |
| **Задача** | **Unit-тесты** (низкоуровневые, эффективные). | **Интеграционные/E2E-тесты** (реалистичное поведение сети, сложная логика). |
| **Окружение** | Прямо в **EVM** (быстро), с доступом к **читерским кодам** (cheatcodes). | В **Node.js** (полноценный язык), через **JSON-RPC** (реалистичное взаимодействие). |
| **Запуск** | `npx hardhat test solidity` | `npx hardhat test nodejs` |
| **Общий Запуск**| `npx hardhat test` (запускает оба типа) | |
| **Отладка** | Подробные **Solidity stack traces** при ошибках. | |

### Скрипты

  * Используйте файлы в `scripts/` для запуска **пользовательской логики** (например, имитация транзакции в Optimism или получение данных из API).
  * **Запуск:**
    ```bash
    npx hardhat run scripts/your-script.ts
    ```

## 🚀 Деплой с Hardhat Ignition

**Hardhat Ignition** — это **официальное, декларативное** решение для деплоя. Вы описываете *цель*, а Ignition сам управляет процессом.

### Основной Принцип

1.  **Определение Модуля:** В `ignition/modules/` вы создаете модуль, используя функции:
      * `m.contract("Counter")`: Развернуть контракт.
      * `m.call(контракт, "incBy", [5n])`: Вызвать функцию после деплоя.
2.  **Запуск Деплоя:**
    ```bash
    npx hardhat ignition deploy ignition/modules/Counter.ts
    ```
    Деплой выполняется в **симулированной сети** для проверки, если сеть не указана.

### Преимущества Hardhat Ignition

  * **Автоматизация:** Обрабатывает зависимости, ошибки, параллельное выполнение.
  * **Возобновление:** Может продолжить прерванный деплой, используя **журнал** (`journal.jsonl`).
  * **Манипуляции:** Поддерживает **верификацию** (`--verify`) и **детерминированный деплой** (`--strategy create2`).
  * **Обновляемость:** Упрощает развертывание **Upgradeable Proxies**.
